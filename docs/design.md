# 素材库界面约定

面向制作酒馆主题的人：找一张装饰、看清透明边界、确认版本、取得可复用地址。

以浅纸色的素材目录承载深色预览格。图片占据主要视野；名称其次，像素尺寸、体积、版本为辅助信息。桌面左侧为图集目录，手机将目录收起为横向选择。详情使用原生 dialog，导入按单张呈现结果。

- 纸色 #f5f3ef；内容面 #fffefa；文字 #252c2a。
- 分隔 #dedfd6；次级文字 #68726d；动作 #315b4c；选中底 #e0ebe4。
- 深色预览 #202b29，可切换浅色或棋盘底。
- 系统字体，标题字标 Georgia。4 px 间距基准，轻边框，少量阴影仅用于弹窗。
- 卡片提供详情和直链快捷复制；编辑入口只出现在本地模式。
- 公开未加载、筛选无结果、导入部分失败、复制受限与并发修改均需要明确反馈。
